# Docker Compose

## 1. What is Docker Compose?

Docker Compose is a tool used to define and run multiple Docker containers as a single application using a configuration file.

## 2. Why do we use Docker Compose?

Docker Compose makes it easier to run and manage multiple services together, configure their networks, ports, environment variables, and volumes.

## 3. Dockerfile vs Docker Compose

A Dockerfile defines how to build a Docker Image for an application.

Docker Compose defines how multiple services should be configured, connected, and run together.

## 4. What is a Service?

A Service in Docker Compose represents a component of the application that runs as a container.

In this project, the two services are Laravel and MySQL.
